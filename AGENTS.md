# Agent Instructions

## CV files (files/CV.pdf, files/CV.md, and any CV source)

- Do NOT modify the CV in any way without the user's explicit permission in the current conversation. "Update the website" or similar general requests do NOT count as permission to touch the CV.
- Do NOT regenerate, reformat, rewrite, or "improve" CV content as a side effect of other website work.

## Behavox work experience section

- NEVER modify the Behavox section of the CV, even when other CV edits are authorized, unless the user explicitly asks for a change to that specific section.
- History: this section was repeatedly rewritten by automated updates when the website was regenerated, and each rewrite lost detail. The current wording was deliberately restored by the user from an older CV and must be preserved verbatim.

## General

- If a task appears to require changing the CV, stop and ask the user first.
- When regenerating the site or PDFs, treat existing CV content as the source of truth; never paraphrase or summarize it.
